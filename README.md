# ビルドクラスタ 工事管理アプリ

スケジュール管理 + タスク管理 + 修繕 + 原状回復 + 在庫管理 を統合した社内Webアプリ。

## 機能
- 📅 スケジュール (カレンダー / 担当別 / 月)
- 📋 タスク管理
- 🔧 修繕・アフターケア (Drive台帳連携)
- 🏠 原状回復 (Drive台帳連携)
- 📦 在庫管理 (品目/発注/棚卸/月次レポート)
- ☁ クラウド同期 (Google Apps Script バックエンド)

## デプロイ
- **アプリ**: GitHub Pages で配信 (`index.html` 1ファイル)
- **バックエンド**: Google Apps Script Web App (`backend/` に GAS コード)

## セットアップ (新規ユーザー)
1. アプリURL をブラウザで開く
2. ヘッダーの ☁ ボタンクリック
3. クラウド同期URLを入力 → 保存
4. 👤マイ ボタンで自分の名前を選択

## 開発
- 単一HTMLファイル (`index.html`) で全機能
- バックエンド更新: `cd backend && bash deploy.sh`
